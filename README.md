## 1. Прогноз оттока клиентов оператора связи
https://github.com/nastasii0/nastasii0.github.io/blob/85558cc2b1c62b5da8b040bdac18c2e5b6056017/customer_churn.ipynb

`Описание проекта:`
Разработала модели машинного обучения для идентификации клиентов, планирующих расторгнуть договор. Проект реализован для оператора связи с целью проведения превентивных маркетинговых акций (промокоды, спецпредложения). Выполнила объединение данных из разных источников, сложный исследовательский анализ (EDA) и глубокую предобработку, включая работу с временными признаками и дисбалансом классов. Провела сравнительный анализ моделей, выбрав наиболее эффективную по метрике ROC-AUC.

`Стек инструментов:`
- Язык и анализ: Python (Pandas, NumPy, Phik, Datetime).
- Машинное обучение: Scikit-learn (Pipeline, ColumnTransformer, RandomizedSearchCV), CatBoost, LightGBM, RandomForest, LogisticRegression.
- Визуализация и метрики: Seaborn, Matplotlib, ROC-AUC (основная метрика), Confusion Matrix, Precision/Recall, ROC-curve.

## 3. Статистический анализ данных аренды самокатов GoFast

`Описание проекта:`

Провела сравнительный анализ двух групп клиентов (с подпиской Ultra и без), рассчитала помесячную выручку и проверила ряд статистических гипотез о длительности поездок и доходности пользователей. Реализовала расчеты вероятностей для маркетинговых акций с использованием биномиального распределения.

## 4. Выбор локации для скважины
https://github.com/nastasii0/nastasii0.github.io/blob/85558cc2b1c62b5da8b040bdac18c2e5b6056017/location_for_the_well.ipynb

`Описание проекта:`

Разработала модели машинного обучения для определения региона с максимальной прибылью от добычи нефти для компании «ГлавРосГосНефть». Провела оценку объема запасов в трех регионах и реализовала расчет бизнес-показателей (прибыль, точка безубыточности). Для оценки финансовой надежности и рисков применила метод Bootstrap, что позволило рассчитать 95%-й доверительный интервал для ожидаемой прибыли и оценить вероятность убытков.

`Стек инструментов:`
- Язык и анализ: Python (Pandas, NumPy).
- Машинное обучение: Scikit-learn (LinearRegression, StandardScaler).
- Бизнес-анализ: Техника Bootstrap, расчет доверительных интервалов и вероятности рисков.
- Визуализация и метрики: Seaborn, Matplotlib, Mean Squared Error (RMSE).
