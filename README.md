## Анализ сотрудников компании «Работа с заботой»
https://github.com/nastasii0/nastasii0.github.io/blob/1fb495de2e6f4d46f125521fb68d807c7c896faa/analysis_of_company_employees.ipynb

`Описание проекта:`

HR-аналитика: прогнозирование удовлетворенности и оттока персоналаКомплексное исследование для оптимизации управления талантами. Спроектировала ML-пайплайны для решения задач регрессии (уровень лояльности) и классификации (риск увольнения). Провела глубокий EDA, сформировала портрет «уходящего сотрудника» и статистически обосновала влияние удовлетворенности на текучесть кадров.

`Стек инструментов:`
- Язык и анализ: Python (Pandas, NumPy, Phik, SciPy).
- Машинное обучение: Scikit-learn (DecisionTree, LinearRegression, LogisticRegression, Pipeline).
- Визуализация и интерпретация: Seaborn, Matplotlib, SHAP.

## Проект: Статистический анализ данных аренды самокатов GoFast
https://github.com/nastasii0/nastasii0.github.io/blob/85558cc2b1c62b5da8b040bdac18c2e5b6056017/statistical_analysis.ipynb

Описание проекта:
- Анализ данных о пользователях и поездках сервиса аренды самокатов GoFast в различных городах
- Исследование характеристик пользователей (возраст, частота поездок, расстояние, продолжительность)
- Расчет выручки для подписчиков и неж sigшпользователей при разных тарифах
- Проверка гипотез о том, что пользователи с подпиской проводят больше времени в поездках и приносят больше дохода
- Использование t-теста для сравнения продолжительности поездок и выручки между группами
- Пользователи с подпиской проводят больше времени и приносят больше выручки, что выгодно для бизнеса
