## Обо мне

Я — Data Scientist, с увлечением исследую данные, создаю визуализации, понятные и эстетичные, а также нахожу практичные решения задач с помощью Python и ключевых библиотек. Постоянно учусь и ищу новые возможности для роста.

Обладаю прочной теоретической базой в теории вероятностей, статистике, линейной алгебре и численных методах. Использую временные ряды и метрики качества для оценки моделей. В работе применяю Python (Jupyter Notebook), а также библиотеки Pandas, Numpy, SciPy, Matplotlib и Seaborn для анализа и визуализации данных. В проектах применяю ML-инструменты: Scikit-learn, XGBoost, LightGBM, CatBoost — для решения задач обучения с учителем. Также владею SQL для работы с базами данных.
