## Анализ сотрудников компании 
https://github.com/nastasii0/nastasii0.github.io/blob/1fb495de2e6f4d46f125521fb68d807c7c896faa/analysis_of_company_employees.ipynb

`Описание проекта:`

HR-аналитика: прогнозирование удовлетворенности и оттока персоналаКомплексное исследование для оптимизации управления талантами. Спроектировала ML-пайплайны для решения задач регрессии (уровень лояльности) и классификации (риск увольнения). Провела глубокий EDA, сформировала портрет «уходящего сотрудника» и статистически обосновала влияние удовлетворенности на текучесть кадров.

`Стек инструментов:`

- Машинное обучение: Scikit-learn (DecisionTree, LinearRegression, LogisticRegression, Pipeline).
- Визуализация и интерпретация: Seaborn, Matplotlib, SHAP.


## Определение стоимости автомобилей
https://github.com/nastasii0/nastasii0.github.io/blob/85558cc2b1c62b5da8b040bdac18c2e5b6056017/car_cost_analysis.ipynb

`Описание проекта:`

Разработка сервиса для автоматической оценки стоимости авто с пробегом на основе технических характеристик и комплектации. Реализовала сравнительный анализ различных алгоритмов (от линейных моделей до градиентного бустинга), оценивая их по трем бизнес-критериям: точность предсказания (RMSE), скорость обучения и скорость инференса. Выполнила полный цикл подготовки данных: обработку пропусков, кодирование признаков и масштабирование.

`Стек инструментов:`
- Язык и анализ: Python (Pandas, NumPy, Time).
- Машинное обучение: Scikit-learn (LinearRegression, RandomForestRegressor, StandardScaler, KFold), LightGBM (LGBMRegressor).
- Визуализация и метрики: Seaborn, Matplotlib, Mean Squared Error (RMSE), R2-score.

## Проект "Вольный луг"
https://github.com/nastasii0/nastasii0.github.io/blob/85558cc2b1c62b5da8b040bdac18c2e5b6056017/cow_selection_model.ipynb

`Описание проекта:`

Разработала системы поддержки принятия решений для фермерского хозяйства. Создала две модели машинного обучения для автоматизации отбора коров в стадо: первая прогнозирует годовой надой (регрессия), вторая оценивает вероятность соответствия молока критериям вкуса (бинарная классификация). Проект позволяет минимизировать риски при покупке новых животных и прогнозировать производительность фермы.

`Стек инструментов:`
- Язык и анализ: Python (Pandas, NumPy).
- Машинное обучение: Scikit-learn (LinearRegression для прогноза удоя, LogisticRegression для оценки вкуса, StandardScaler, OneHotEncoder).
- Визуализация и метрики: Matplotlib, R2-score (для регрессии), Accuracy, Recall, Precision, Confusion Matrix (для классификации).

## Выбор локации для скважины
https://github.com/nastasii0/nastasii0.github.io/blob/85558cc2b1c62b5da8b040bdac18c2e5b6056017/location_for_the_well.ipynb

`Описание проекта:`

Разработала модели машинного обучения для определения региона с максимальной прибылью от добычи нефти для компании «ГлавРосГосНефть». Провела оценку объема запасов в трех регионах и реализовала расчет бизнес-показателей (прибыль, точка безубыточности). Для оценки финансовой надежности и рисков применила метод Bootstrap, что позволило рассчитать 95%-й доверительный интервал для ожидаемой прибыли и оценить вероятность убытков.

`Стек инструментов:`
- Язык и анализ: Python (Pandas, NumPy).
- Машинное обучение: Scikit-learn (LinearRegression, StandardScaler).
- Бизнес-анализ: Техника Bootstrap, расчет доверительных интервалов и вероятности рисков.
- Визуализация и метрики: Seaborn, Matplotlib, Mean Squared Error (RMSE).


## Статистический анализ данных аренды самокатов GoFast

`Описание проекта:`

Провела сравнительный анализ двух групп клиентов (с подпиской Ultra и без), рассчитала помесячную выручку и проверила ряд статистических гипотез о длительности поездок и доходности пользователей. Реализовала расчеты вероятностей для маркетинговых акций с использованием биномиального распределения.

- Язык и анализ: Python (Pandas, NumPy).

- Визуализация: Matplotlib (распределения, сравнительные гистограммы).
